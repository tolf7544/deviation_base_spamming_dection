- 목적 - 
variance ratio의 분포에 통계적 분석을 진행하기 위하여 variance ratio의 정규성 검증을 진행한다.
현재 10만개 데이터에서 시각적으로 명확히 정규 분포에 근사한 형태를 보인다. 즉 중심 극한 정리를 띄기에 모집단은 정규분포를 이룬다고 가정할 수 있으며 시각적으로 정규분포를 이루는지 
시각적으로 확인이 불가능한 최소한의 데이터에서 정규성을 가질 수 있도록 box-cox를 통하여 최적의 람다(lmbda)값을 찾고 이를 샤피로 월크 검정을 통해 정규성 검정으로 확인하여 분석을 진행한다.

- 제약 조건 -
하나의 표본점(variance ratio)는 3개의 시계열 데이터(추세를 가지는 증가하는 데이터 집합)를 요구한다. 그렇기에 실사용 시 최소한의 표본 크기로 정규분포를 이루도록 하여 효율적인 통계 분석의 기반을 다지도록 해야한다.

- 결과 요약 -
결과적으로 정규 분포를 형성하는데 최소 조건인 샘플 갯수 30개를 시작으로 10을 간격으로 증가하여 100개까지의 경우를 분석한 결과 다음과 같았다.

1. 유의수준 0.05 이상일 시 귀무가설(데이터가 정규분포를 따른다)을 채택하며 0.05 이하일 시 대립가설(데이터가 정규분포를 따르지 않는다.)로 정의할 수 있다. 
해당 분석 결과는 평균적으로 약 0.57의 p-value를 가지기에 데이터는 정규분포를 따른다.

2. 가중 평균을 통해 최적의 lmbda를 구한 결과는 1.15이다.

- 결론 -
30~100 사이 크기의 표본 공간에서 평균적으로 1.15 lmbda값에 0.57의 유의확률를 가지며 정규성을 가진다.

정규성을 가지는 30-100의 데이터의 정의 = MinMaxNormalization > box-cox( lambda-1.15 )
